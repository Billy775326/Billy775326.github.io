当访问 GitHub.com 的 SSH 22 端口受网络规则限制时，可以尝试通过 ssh.github.com:443 连接。这里仍然使用 SSH 协议，443 是连接端口；HTTP 代理或只允许 HTTPS 流量的网络仍可能拦截它。

本文假定你已经生成 SSH 密钥并把公钥添加到对应 GitHub 账号。该入口面向 GitHub.com，不适用于 GitHub Enterprise Server 或带数据驻留的 GitHub Enterprise Cloud。配置与范围见 GitHub 官方说明。

1.测试443端口是否可用

首次连接可能要求确认主机密钥，先与 GitHub 公布的 SSH 指纹核对。认证成功时会看到类似输出，其中 UserName 是你的账号名：

Hi UserName! You’ve successfully authenticated, but GitHub does not provide shell access.

这条提示说明认证成功；GitHub 不提供交互式 Shell 是正常行为。若出现 Permission denied (publickey)，应检查使用的密钥和账号授权。
