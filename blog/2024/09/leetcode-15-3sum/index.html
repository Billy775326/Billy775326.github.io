15.三数之和

题目描述

给你一个整数数组 nums ，判断是否存在三元组 [nums[i], nums[j], nums[k]] 满足 i != j、i != k 且 j != k ，同时还满足 nums[i] + nums[j] + nums[k] == 0 。请

你返回所有和为 0 且不重复的三元组。

**注意：**答案中不可以包含重复的三元组。

  • 3 <= nums.length <= 3000

解题

总体思路是参考1.两数之和，三数之和的话，只需选定一个数假定为A，那么就转化为两数之和问题了，要求解的另外两个数假定为B和C，满足B+C=-A，即两数之和问题。
